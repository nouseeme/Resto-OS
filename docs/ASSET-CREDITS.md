## Fonts

The interface serves Newsreader and Manrope locally. Both use the SIL Open Font License; retain the original license files when redistributing them.

- [Newsreader license](../public/fonts/Newsreader-OFL.txt)
- [Manrope license](../public/fonts/Manrope-OFL.txt)

Font binaries live in `public/fonts`; moving this document does not move those assets or their licenses.

## Icons and serving mark

Interface icons come from the declared Lucide dependency. The restaurant serving mark is an inline SVG in the application. Keep applicable dependency license notices when distributing the application.

## Menu photography

Normal restaurant installations obtain photos from staff uploads and start with an empty catalog. The explicitly enabled demo uses fictional menu items and external Unsplash image URLs recorded in [demo-seed.js](../server/demo-seed.js). These photos illustrate fictional dishes; they are not evidence of a real restaurant catalog.

See the [Unsplash License](https://unsplash.com/license) and the recorded source URLs before reusing demo imagery outside its existing context. Uploaded restaurant images require the operator's own rights to use them.
